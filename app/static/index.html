OpenSky Network

Live positions. Create an API client at opensky-network.org → Account. Without credentials requests are anonymous (400 credits/day, ≈1 poll every 4 minutes); with credentials you get 4,000/day.

FlightAware AeroAPI

Flight numbers, routes and aircraft types. Get a key at flightaware.com/aeroapi. Only the flight shown on the board is looked up, and results are cached, to keep costs down.
